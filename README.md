# ☕ Barista Coffee Shop Website

A modern, responsive website for a coffee shop featuring an interactive menu, online table booking, shop functionality, and educational content about coffee. Built with HTML, CSS, Bootstrap, and JavaScript.

![Barista Coffee](./Barista_pic/Logo.webp)

## 🌟 Features

### 🏠 Home Page
- Responsive Bootstrap carousel slider showcasing the café's ambiance
- "What Happens Here" section highlighting the café's unique offerings
- Opening hours and contact information
- Mobile application promotion section
- Latest blog posts and news updates

### 📋 Menu Page
- Interactive tabbed menu system with three categories:
  - **Coffee** - Espresso, Latte, Mocha, Cold Brew, and more (₹60 - ₹700)
  - **Snacks** - Chips, Cookies, Samosas, Energy Bars, and more (₹10 - ₹100)
  - **Tea** - Masala Chai, Green Tea, Bubble Tea, and more (₹20 - ₹150)
- Dynamic menu switching with JavaScript

### 🛒 Shop Page
- E-commerce style product grid featuring:
  - Ceramic cups and mugs (various designs and sizes)
  - Coffee machines (Espresso, Pour Over, Moka Pot, French Press)
- Product cards with images, descriptions, and pricing
- "Shop Now" call-to-action buttons

### 📅 Booking/Reservation Page
- Online table reservation system
- Form fields include:
  - Name, Email, Phone
  - Location selection (3 branches)
  - Date and Time picker
  - Order timing preference (Now/Schedule)
  - Payment options (Cash, UPI, Debit/Credit Card)
  - Table size selection (1-6+ people)

### 📖 Know Your Coffee (Blog)
- Educational content about coffee brewing
- Information about bean selection and sourcing
- Brewing methods and recipes
- Details about signature drinks (Latte, Mocha, Chai Latte)

## 🛠️ Tech Stack

- **HTML5** - Semantic markup and structure
- **CSS3** - Custom styling with CSS variables and responsive design
- **Bootstrap 4.6** - Responsive grid system and components
- **JavaScript (ES6)** - Interactive menu functionality
- **Font Awesome 5.10** - Icons and UI elements
- **jQuery 3.5.1** - DOM manipulation (via Bootstrap)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Ananya21-G/Barista-Website.git
cd Barista-Website
```

2. Open `index.html` in your web browser, or serve it using a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```

3. Visit `http://localhost:8000` in your browser
